# مُسعِّر عروض الأسعار

أداة لإعداد عروض الأسعار بسرعة: قائمة أسعار، وعملاء، وحساب الهامش والخصم وضريبة القيمة المضافة 15%، ثم تصدير العرض PDF أو إرساله واتساب.

- كل شيء في ملف واحد: `index.html`، بدون خادم وبدون تثبيت.
- البيانات تُحفظ في متصفح المستخدم (localStorage) ولا تُرفع لأي مكان. خذ نسخة احتياطية من تبويب «الإعدادات».
- يُنشر عبر GitHub Pages من فرع `main`.
