# مُسعِّر العروض البيئية

نظام لتسعير خدمات الاستشارات البيئية (خطط ودراسات NCEC) وإصدار عروض الأسعار على ترويسة الشركة.

- التسعير حسب الفئة البيئية (الأولى/الثانية/الثالثة)، والقياسات البيئية (تكلفة المختبر)، والسجلات، والسفر (سيارة/قطار/طيران + سكن وسيارة وبدلات)، والرسوم الحكومية.
- السعر = التكلفة × (1 + هامش المخاطر) ÷ (1 − هامش الربح)، مع هامش مستقل للمختبر.
- معاينة العرض كصفحات A4 مع تعديل النصوص مباشرة، ثم تنزيله PDF أو Word أو طباعته.
- ملف واحد `index.html` بدون خادم؛ البيانات تُحفظ في متصفح المستخدم (localStorage). خذ نسخة احتياطية من «الأسعار والإعدادات».
